# E3b protocol (registered before mining)

## Source and split
Published τ²-bench retail and airline trajectories at commit `768f3d8fe8528b4f32a5096f9ed008ae50f48ead`, all rewards and trials included. Mine each domain separately using all gpt-4.1 episodes. Evaluation comprises every available occurrence in claude-3-7-sonnet, gpt-4.1-mini and o4-mini episodes. Assign gpt-4.1 task IDs to calibration by SHA-256 of `e3b-calibration:<domain>:<task_id>` modulo 5 == 0; other gpt-4.1 task IDs supply writer examples and the majority baseline. This keeps calibration out of question writing and held-out models out of mining, writing, and threshold selection. Same tasks can appear across models: the split tests model transfer, not unseen-task generalization.

## Discovery and labels
Apply `mine` once per domain with min_support=10, max_cardinality=255 and default copied/free-text rules. The candidate universe is *every* emitted candidate, accepted or rejected, including rare and constant ones; retain the full report and reasons. Label candidates by the frozen domain rules in `decision_labels.yaml`, independent of acceptance: a policy-relevant choice among actions or bounded substantive options is a judgement; copied identifiers, text, quantities, arguments used to access data and incidental lookup branches are distractors. All unlisted candidates are distractors. Branch labels denote whether an action is ever performed in an episode, not a concrete moment. This coding is an investigator-authored proxy, not independent human annotation; report its sensitivity and the prevalence. The miner has no representation for asking for confirmation or a multiclass choice among write actions: these important undeclared decisions cannot be discovered by this candidate universe, so recall does not cover them and does not establish C1. An action-tool branch is only a binary proxy for the write-action decision.

## Questions and instances
Draft each accepted labelled judgement using `OpenAIQuestionWriter(gpt-6.1-terra)`, at most 20 examples sampled reproducibly with seed 0. The writer sees only sampled `(prefix, value[, title])`; no policy documents, tool results or held-out examples. Question options are the distinct training-side observed values. A missing or invalid question is a failure, not an exclusion hidden from reporting. Evaluate each occurrence of each eligible tool-argument judgement in held-out episodes. An episode-wide tool-ever-called branch has no unique observable pre-decision boundary, and retrieval choices have no valid extracted boundary; do not fabricate a boundary or score them, but report their non-evaluability.

The state contains user/assistant text before the deciding tool-call turn and results of preceding calls as structured JSON, never the deciding call or later information. Apply the same deterministic truncation to calibration and evaluation: retain the most recent transcript entries and previous tool results within the extraction code's documented cap. A gold argument exists only when the task contains matching actions with exactly the same tool name and argument and all matching gold values agree; otherwise gold is missing, not an error. Teacher is the actual tool argument. Never infer branch gold from a missing gold action.

## Metrics and budget
Per decision and pooled, report teacher and available-gold accuracy and 95% Wilson intervals, majority baseline from writer-side training occurrences, top-probability risk-coverage and AURC with 95% task-cluster bootstrap intervals (2,000 resamples, seed 0). Calibration chooses the threshold yielding greatest coverage among tied-score groups with empirical teacher error ≤ 5%; if none qualifies, serve nothing. Evaluate the fixed threshold on held-out data; report its coverage and risk and intervals, not a guarantee. Refusals and API errors are reported and never silently treated as correct. Compare gold on its available subset and report its denominator. Costs capped at $3 TypeSafe and $5 OpenAI for uncached calls; stop rather than silently sample. Every paid request must be cached and replay must fail closed on a miss. Models are pinned (`jev-1.14.0`, `gpt-6.1-terra`).

## Interpretation
This is an exploratory model-transfer analysis of published user-simulator trajectories, not an intervention and not proof of utility or policy correctness. Discuss user-simulator behaviour, teacher noise, decision ambiguity, reward selection (none here), repeated trials/tasks and dataset/model contamination. Gold action lists can omit acceptable actions. No firstness claim is made for LLM-written typed questions (TypeSafe Autoresearch and DSPy are prior art).
